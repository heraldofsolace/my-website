# Monorepo layout

This is an Nx-managed npm workspace with two apps:

- `frontend/` — the Next.js portfolio site. Its own `AGENTS.md`/`CLAUDE.md`
  (auto-regenerated by `next dev`/`next build`) has the Next.js-specific
  rules — read that before touching anything under `frontend/`.
- `backend/` — reserved for a Strapi instance (not yet scaffolded).

Dependencies are hoisted to the root `node_modules` via npm workspaces
(`package.json` → `workspaces`). Run tasks through Nx from the repo root,
e.g. `npx nx run frontend:dev`, `npx nx run-many -t build`, or the root
`npm run dev` / `npm run build` / `npm run lint` shortcuts. `nx.json` defines
target defaults (build caching/outputs, etc.) shared across workspace
projects — extend it there rather than duplicating config per-package.

`node_modules/next` is not present under `frontend/` — it resolves via
normal upward node_modules lookup to the hoisted copy at the repo root.
